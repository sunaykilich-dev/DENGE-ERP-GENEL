DENGEERP V1.20 — KURULUM / TEST
============================
1. Mevcut V1.14'ü KAPATMAYIN.
2. ZIP dosyasini C:\DengeERP\App klasorune koyun.
3. YENI PowerShell'de kodu TEK SEFERDE calistirin:

$zip='C:\DengeERP\App\DengeERP_Pilot_V1_20_BIRLESIK_PAKET_2026-10-15.zip'
if(!(Test-Path $zip)){throw 'ZIP bulunamadi: '+$zip}
$hedef='C:\DengeERP\App\DengeERP_V1_20_TEMIZ_'+(Get-Date -Format yyyyMMdd_HHmmss)
Expand-Archive -LiteralPath $zip -DestinationPath $hedef -ErrorAction Stop
$proje=Get-ChildItem $hedef -Recurse -Filter 'DengeERP.Api.csproj' | Select-Object -First 1
if(!$proje){throw 'Proje dosyasi yok'}
dotnet build $proje.FullName

4. DERLEME BASARILIYSA SSMS / Yeni Sorgu'da yedekleme:
USE master;
GO
DECLARE @K NVARCHAR(400)=CONVERT(NVARCHAR(400),SERVERPROPERTY('InstanceDefaultBackupPath'));
DECLARE @P NVARCHAR(500)=@K+CASE WHEN RIGHT(@K,1)='\' THEN '' ELSE '\' END+
 'DengeERP_V114_BIRLESIK_ONCESI_'+FORMAT(GETDATE(),'yyyyMMdd_HHmmss')+'.bak';
BACKUP DATABASE DengeERP TO DISK=@P WITH COPY_ONLY,CHECKSUM,INIT,STATS=10;
RESTORE VERIFYONLY FROM DISK=@P WITH CHECKSUM;
SELECT @P AS YedekDosyasi;

5. Hem BACKUP hem VERIFYONLY basariliysa eski V1.14 PowerShell'de Ctrl+C.
6. V1.20 PowerShell'de:
Set-Location $proje.DirectoryName
dotnet run --urls 'http://0.0.0.0:5050'
