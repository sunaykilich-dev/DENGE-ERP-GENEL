DengeERP Pilot V1 - 13.10.2026
================================

Bu sürüm, 12 Ekim akşamı gönderilen çalışan DengeERP.Api projesi temel alınarak pilot kullanıma göre yeniden bütünleştirildi.

EKLENEN / GERÇEK SQL'E ALINANLAR
- SQL tabanlı kullanıcı / parola / rol / yetki yönetimi
- PBKDF2 parola hashleme ve ilk girişte parola değiştirme
- Kullanıcı bazlı birim + modül + işlem yetkileri
- Güvenlik, Haberleşme, POC, Mobilite, Araç Takip ortak altyapısı
- İş emri sistem adı, müşteri e-posta, seri numarası alanları
- Çoklu seri numarası tablosu
- İş türü kural tablosu (açılışta/kapanışta seri no zorunluluğu)
- Durum değişiklik geçmişi SQL tablosu
- Mevcut şef/teknisyen ataması ve plan tablosu ile bütünleşme
- Web ekranından gerçek plan kaydı
- Teklif ana kaydı + teklif kalemleri + iskonto/KDV/toplam
- Teklif onay durumu
- Temel PDF teklif çıktısı
- SMTP yapılandırması sonrasında standart e-posta + PDF eki
- Günlük / haftalık / aylık / özel tarih aralığı Excel export
- Excel filtreleri: birim, durum, iş türü, teknisyen/personel, şef
- Excel: Özet + İş Emirleri sayfaları
- LAN pilot kullanımı için 0.0.0.0:5050 ve firewall yardımcı scripti

BILEREK KPI/SLA'DA YAPILMAYAN
- Yönetim KPI hedefleri ve SLA eşikleri sabitlenmedi.
- Gerçek operasyon verileri ile son yönetici dashboard aşamasında tanımlanacak.

SONRAKI ITERASYONLAR

- Planlı bakım periyot motoru
- Depo / muhasebe / satış / satınalma alt görev yönlendirmeleri
- Offline teknisyen veri senkronizasyonu
- Koordinat tabanlı rota optimizasyonu
- Teklif PDF kurumsal şablon / logo / imza detayları
